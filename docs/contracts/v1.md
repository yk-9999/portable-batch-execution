# Contract v1

Pydantic v2 frozen, extra-forbid models define durable input manifests, jobs,
shards, waves, attempt records, and immutable manifest revisions. The generated
JSON Schemas are committed under `schemas/v1` and are regenerated with
`uv run python scripts/export_schemas.py`.

Jobs use a closed pack and operation pair, JSON-compatible operation parameters,
and one of `offline`, `bounded-network`, or `external-api` security profiles.
Executable text, import/callback dispatch, and secret-bearing artifact URIs are
rejected. Shard attempts carry the input digest and execution fingerprint used
by the kernel's resume and completeness decisions.
