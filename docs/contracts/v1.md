# Contract v1

Pydantic v2 frozen, extra-forbid models define durable input manifests, jobs,
shards, waves, attempt records, and immutable manifest revisions. The generated
JSON Schemas are committed under `schemas/v1` and are regenerated with
`uv run python scripts/export_schemas.py`.

Jobs use a closed pack and operation pair, JSON-compatible operation parameters,
and one of `offline`, `bounded-network`, or `external-api` security profiles.
Executable text, import/callback dispatch, and secret-bearing artifact URIs are
rejected. Shard attempts carry the input digest and execution fingerprint used
by the kernel's resume and completeness decisions.

The tabular pack additionally provides two bounded closed operations.  `tabular.text_event_features.v1`
accepts only rows with the fixed `row_id`, partition, segment, timestamp, entity,
and text fields and emits long-form integer feature contributions.  Its Unicode,
case, whitespace, and finite character n-gram parameters are typed.  `tabular.trailing_sparse_window_aggregate.v1`
accepts only a fixed feature/request envelope and computes exact half-open trailing
windows.  Both reject input byte, row, unique-key, or output-row cap excess; the
window operation also rejects invalid requests and insufficient declared time halo.
