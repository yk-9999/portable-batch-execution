# Architecture v1

The v1 kernel owns shard planning, wave planning, retry eligibility,
completeness, and finalization. `RunController` is the sole RunManifest writer
and uses the data plane's compare-and-swap revision boundary. Workers append
attempt records; a canonical success must match both the shard input digest and
execution fingerprint.

Packs implement the closed `validate_params`, `execute`, and `finalize`
boundary. Tabular, acquisition, ML, and media operations are portable
implementations. Replay/evaluation accepts a trusted project adapter at
construction and delegates project semantics to it; manifests never provide an
import path or callback.

The local data plane owns immutable artifact and revision persistence. The
GitHub Actions backend only dispatches a planned wave, looks up or cancels a
returned execution reference, and produces portable evidence. GitHub waves are
capped at 256 shards. Jobs cannot carry shell, Python, SQL, imports,
credentials, or private data.
