# Architecture v1

The Kernel plans shards/waves, owns resume/completeness/finalization, and is the
only RunManifest writer. Packs validate closed operations. Trusted adapters own
project semantics; data planes own immutable artifacts and state; backends only
submit, inspect, cancel, and collect evidence. GitHub Actions waves cap at 256.
Jobs cannot carry shell, Python, SQL, imports, credentials, or private data.
